# 🚀 Руководство по активации GitHub Pages

Это руководство поможет вам активировать автоматическое развертывание на GitHub Pages.

## ✅ Статус готовности

- ✅ GitHub Actions workflow настроен (`.github/workflows/deploy.yml`)
- ✅ Главная страница создана (`index.html`)
- ✅ HTML отчеты готовы к публикации (`report.html`, `report2.html`)
- ✅ Документация обновлена (`README.md`)

## 📋 Шаги активации

### Шаг 1: Объединить Pull Request

1. Перейдите в ваш Pull Request на GitHub
2. Проверьте все изменения
3. Нажмите **"Merge pull request"**
4. Выберите ветку **`main`** или **`master`** в качестве целевой

### Шаг 2: Включить GitHub Pages

1. Откройте ваш репозиторий на GitHub
2. Перейдите в **Settings** (Настройки) репозитория
3. В левом меню найдите секцию **Pages**
4. В разделе **"Build and deployment"**:
   - **Source**: выберите **"GitHub Actions"**
   - Сохраните изменения

### Шаг 3: Запустить первое развертывание

После включения GitHub Pages:

**Автоматически:** 
- Workflow запустится автоматически при следующем push в `main`/`master`

**Вручную (рекомендуется для первого раза):**
1. Перейдите во вкладку **"Actions"** в вашем репозитории
2. Выберите workflow **"Deploy to GitHub Pages"** в левом меню
3. Нажмите **"Run workflow"** (справа)
4. Выберите ветку **`main`** или **`master`**
5. Нажмите зеленую кнопку **"Run workflow"**

### Шаг 4: Дождаться завершения

1. Workflow начнет выполнение (обычно 30-60 секунд)
2. Вы увидите зеленую галочку ✓ когда развертывание завершится
3. В логах workflow вы найдете URL вашего сайта

## 🌐 Доступ к развернутому сайту

После успешного развертывания ваши отчеты будут доступны по адресам:

- **Главная страница**: `https://<USERNAME>.github.io/problem-tables-report/`
- **Прототип отчета**: `https://<USERNAME>.github.io/problem-tables-report/report2.html`
- **Базовый отчет**: `https://<USERNAME>.github.io/problem-tables-report/report.html`

Замените `<USERNAME>` на имя владельца репозитория (например, `dssalkov-jpg`).

## 🔍 Проверка статуса

### Как проверить, что все работает:

1. **GitHub Actions**: Зеленая галочка на вкладке Actions означает успешное развертывание
2. **Pages Settings**: В Settings → Pages вы увидите зеленую полосу с текстом "Your site is live at..."
3. **Доступность**: Откройте URL в браузере - вы должны увидеть страницу с отчетами

## 🔧 Устранение проблем

### Workflow не запускается?
- Убедитесь, что изменения смержены в `main` или `master`
- Проверьте, что GitHub Actions включены для репозитория (Settings → Actions → General)

### Страница показывает 404?
- Подождите 1-2 минуты после первого развертывания
- Проверьте, что в Settings → Pages выбран источник "GitHub Actions"
- Убедитесь, что workflow завершился успешно (зеленая галочка в Actions)

### Изменения не отображаются?
- Очистите кеш браузера (Ctrl+F5 или Cmd+Shift+R)
- Проверьте, что последний workflow выполнился успешно

## 📱 Автоматические обновления

После активации:
- Любой push в ветку `main` или `master` автоматически обновит сайт
- Изменения появятся на сайте через ~1 минуту после push

## 🆘 Нужна помощь?

Если возникли проблемы:
1. Проверьте логи workflow в разделе Actions
2. Убедитесь, что все файлы (index.html, report2.html) присутствуют в репозитории
3. Проверьте права доступа к репозиторию (нужны права на запись)
